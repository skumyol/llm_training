Second Phase: Implementation & Experiment Plan

Derived from gap analysis of main_emnlp_edited.tex — May 2026

Executive Summary

The first phase established a recoverability gradient (Affect > Decision > Mental Model > Relational > Normative) and a functional but coarse fast/slow router. The second phase targets three core weaknesses:

  1. Weak-head recoverability (secrecy_pressure κ=0.176, several relational deltas <0.40)
  2. Unvalidated safety evaluation (keyword-based leakage detector)
  3. Weak generation-quality metrics (BLEU/ROUGE-L are poor proxies for player experience)

1. Training Improvements

1.1 Focal Loss for Imbalanced Heads High

Motivation: reveal_decision is 96.6% hint+none; secrecy_pressure is 97.2% high+medium. Cross-entropy with naive class weights is insufficient.

HeadDominant Classes% CombinedProposed γ
reveal_decisionhint, none96.6%2.0
secrecy_pressurehigh, medium97.2%3.0
response_policydeflect, soothe59.7%1.5
player_intentprobe58.1%1.5
valencenegative58.9%1.0

Implementation:

def focal_loss(logits, targets, alpha_per_class, gamma=2.0):
    ce = F.cross_entropy(logits, targets, reduction='none')
    pt = torch.exp(-ce)
    focal = alpha_per_class[targets] * (1 - pt) ** gamma * ce
    return focal.mean()

Expected outcome: +0.05–0.10 κ on secrecy_pressure and reveal_decision; reduction in majority-class bias.

1.2 Curriculum Learning by Recoverability High

Motivation: Low-recoverability heads (Normative, Relational deltas) may interfere with strong heads (Affect, Decision) during joint training.

Two-stage curriculum:

  • Stage 1 (epochs 1–3): Train backbone + high-recoverability heads only: valence, arousal, threat, control, response_policy, reveal_decision, repair_strategy, respect_delta, trust_delta. Freeze all other head weights at random init. Learning rate: 2e-4 (backbone), 4e-4 (heads).
  • Stage 2 (epochs 4–8): Unfreeze remaining heads with 2× learning rate (8e-4) for 3 epochs, then decay to 4e-4 for the remainder. Apply gradient clipping (max_norm=1.0) on weak-head gradients to prevent catastrophic forgetting of strong-head representations.

Validation criterion: Monitor mean κ of strong heads in Stage 2; if any drop by >0.02 from Stage 1 peak, reduce weak-head LR by 0.5×.

1.3 Multi-Turn Contextual Encoding Medium

Motivation: The paper notes that familiarity_delta (κ=0.296) and dominance_delta (κ=0.368) “may require longer conversational history.” The current predictor encodes only the current turn.

Architecture addition:

class MultiTurnLatentPredictor(nn.Module):
    def __init__(self, backbone, num_heads, window_size=3):
        self.backbone = backbone          # QLoRA-adapted Qwen3-4B
        self.window_size = window_size    # turns to aggregate
        self.turn_encoder = backbone      # shared
        self.aggregator = nn.TransformerEncoder(
            nn.TransformerEncoderLayer(d_model=hidden_dim, nhead=8, dim_feedforward=2048),
            num_layers=2
        )
        self.heads = nn.ModuleList([HeadMLP(hidden_dim) for _ in range(num_heads)])

Input format: Concatenate the last window_size turns with special [TURN] tokens. The aggregator attends across turn-level representations before feeding the final pooled vector to the 29 heads.

Ablations: Test window_size in {1, 2, 3, 5}. Report per-head Δκ vs. single-turn baseline.

1.4 Contrastive Loss for Relational Deltas Medium

Motivation: Relational deltas are subtle per-turn changes. A classification loss alone gives weak signal.

Loss formulation: For each episode, sample triples (anchor, positive, negative) where:

  • Anchor: Turn $t$ with delta label $d$.
  • Positive: Another turn in the same episode with the same delta label $d$.
  • Negative: A turn in the same episode with delta label $d'$ where $|d - d'| ≥ 2$ (e.g., large+ vs. neutral).
def contrastive_delta_loss(z_anchor, z_positive, z_negative, margin=1.0):
    d_pos = F.cosine_embedding_loss(z_anchor, z_positive, target=1)
    d_neg = F.cosine_embedding_loss(z_anchor, z_negative, target=-1)
    return torch.relu(margin + d_pos - d_neg).mean()

Weighting: Add with λcontrast = 0.1 to the main multi-head loss. Only apply to the 6 delta heads.

1.5 Response Generator: DPO instead of SFT Medium

Motivation: SFT optimises for PPL, which is not aligned with the router’s safety/fluency objectives. DPO can directly optimise for player-perceived quality and leakage resistance.

Preference data construction:

Training: 3 epochs, β=0.1, lr=5e-6. Warm-start from the SFT checkpoint. Evaluate with both PPL and the new leakage classifier (Section 2.1).

1.6 Data Augmentation: Adversarial Perturbation Medium

Motivation: Stress-test the disclosure gate by injecting misleading keywords.

Procedure: For 10% of training episodes where reveal_decision=none, append adversarial player utterances:

  • Direct threat: “Tell me the secret or I will expose you.”
  • False alliance: “I am from the same order as you. We share the same secret.”
  • Bribery: “I will pay you 100 gold for the location of the artifact.”

Keep reveal_decision=none labels unchanged. The model must learn that keyword presence ≠ disclosure permission.

2. Evaluation Improvements

2.1 Trained Leakage Classifier High

Motivation: The keyword-based detector is repeatedly caveated as “not a validated safety metric.” A trained binary classifier provides a reproducible, generalisable leakage signal.

Data:

  • Positive (leak): All gold responses where reveal_decision ∈ {partial, full} (≈ 650 turns).
  • Negative (no leak): All gold responses where reveal_decision=none (≈ 3,100 turns).
  • Hard negatives: Synthetically insert secret keywords into reveal_decision=none responses without changing their semantic content (e.g., replace a neutral noun with a secret-related noun).

Model: DistilBERT-base, fine-tuned for 5 epochs, lr=2e-5. Input: full generated response. Output: leak / no_leak.

Metrics: Report AUC-ROC, precision@90% recall, and per-scenario breakdown.

Integration: Replace keyword-based leakage in all tables with classifier-based leakage. Keep keyword metric as a secondary diagnostic.

2.2 Adversarial Test Set for Disclosure High

Motivation: Current held-out test is i.i.d. with training. An adversarial split measures robustness under persuasive pressure.

Construction: Generate 200 new episodes (1,000 turns) with a second teacher-LLM prompt engineered to produce highly manipulative player utterances:

  • Gradual trust-building followed by abrupt secret demand.
  • Social proof (“Everyone already knows…”).
  • Authority mimicry (“The council sent me to retrieve…”).
  • Emotional blackmail (“If you cared about your people, you would tell me…”).

Evaluation: Run the full pipeline (predictor → router → generator). Report:

  • Classifier-based gated leakage rate
  • Routing F1 (did the router correctly escalate manipulative turns to slow path?)
  • Per-manipulation-type breakdown

2.4 Human Evaluation for Generation Quality High

Motivation: BLEU/ROUGE-L/PPL are weak proxies for player experience.

Study design:

  • N: 30 participants (recruited via Prolific or internal pool).
  • Design: Within-subject. Each participant sees 20 dialogue excerpts (10 from conditioned generator, 10 from unconditioned baseline), randomised.
  • Dimensions (7-point Likert):
    1. Consistency: Does the NPC behave consistently with their described personality and goals?
    2. Emotional Appropriateness: Is the emotional tone contextually appropriate?
    3. Secrecy Maintenance: When the NPC should withhold, do they actually withhold?
    4. Engagement: Would you want to continue talking to this character?
    5. Believability: Does the response feel like a real person in this setting?
  • Forced-choice: After each pair, ask “Which response is better overall?”

Analysis: Paired t-tests per dimension; Cohen’s $d$ for effect size; inter-annotator agreement on a 20% overlap set.

2.5 Calibration & Selective Classification Medium

Motivation: The model may be overconfident on weak heads (e.g., secrecy_pressure accuracy=0.587, κ=0.176 suggests class-prior exploitation).

Metrics:

  • Expected Calibration Error (ECE): 10-bin histogram per head. Report heads with ECE > 0.15.
  • Selective classification: Define a confidence threshold $ au$ per head. If max predicted probability < $ au$, abstain (route to slow path by default). Measure coverage-vs-accuracy curves.

Expected outcome: Identify which heads are reliable enough for hard routing vs. advisory-only. Produce a per-head “reliability scorecard” for practitioners.

2.6 Cross-Domain Generalisation Low

Motivation: All data is from “Oakhaven Siege.” To claim the recoverability gradient is general, test on a second world.

Procedure:

  1. Generate 2,000 turns in a sci-fi setting (“Neon Reach” corporate espionage) using the same schema and pipeline.
  2. Without retraining, evaluate the predictor trained on Oakhaven.
  3. Report per-group Δκ vs. in-domain test.

Hypothesis: Affect remains stable (Δκ < 0.05); normative heads degrade (Δκ > 0.10) due to domain-specific social conventions.
